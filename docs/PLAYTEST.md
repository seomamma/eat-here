# Playtest guide

A 20-minute session to find out whether the game is fun and where it breaks. Thanks for helping!

## Run it

**On the computer**

```bash
npm install        # first time only
npm run dev        # open the http://localhost:5173 address it prints
```

**On your phone** (same Wi-Fi as the computer)

```bash
npm run dev -- --host
```

Open the `Network:` address it prints (for example `http://192.168.1.20:5173`) in the phone's browser. If it does not load, check that the computer's firewall allows the port.

Tips: tap **New Game** on the title screen. Sound starts after your first tap. Turn sound and music on or off in **Menu > Settings**.

## 20-minute checklist

Tick things off as you go. Note anything odd, even if it feels small.

1. **First day.** Start a New Game and just watch one day. Do you understand what is going on? Tap a guest to see their happiness.
2. **Buy and place a plant with your finger.** Menu > Shop > Potted Plant. Drag it onto the floor, rotate it, confirm. Does it feel easy?
3. **Move a table after closing.** When the day report appears, continue to the next day, then Menu > Build and move a table. Can you tell what is allowed and what is not?
4. **Upgrade a recipe.** Menu > Market for ingredients, Menu > Recipes to upgrade. Did you know what to do next?
5. **Check the money breakdown.** Tap the money card at the top. Does it match what you expected?
6. **Reach Rank 2.** Keep playing until RANK UP. Was the goal clear? How long did it take (about 4 in-game days)?
7. **Reload and Continue.** Refresh the page, then tap Continue. Is everything where you left it?
8. **Rotate the phone** (portrait and landscape). Does everything stay on screen and tappable?
9. **Sound.** Are the sounds pleasant? Anything too loud, too repetitive, or annoying? Try turning music off and on.
